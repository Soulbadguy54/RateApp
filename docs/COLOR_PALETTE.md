# Rate APP · палитра интерфейса

**Статус:** выбранная базовая палитра дизайна (25.10.2026; PR #60, staging до визуальной приёмки). [Правила проекта](../AGENTS.md) · [решения](DECISIONS.md) · [контекст](PROJECT_CONTEXT.md).

## Правило для будущих доработок

В приложении не нужно придумывать отдельный цвет для каждого нового действия. Сначала использовать существующую семантическую роль: нейтральная поверхность, зелёное положительное действие, холодное синее отклонение, розовое «Хочу поиграть». Для дизайна возможны более светлые/тёмные версии **одного и того же** оттенка (фон, текст, дымка), но не соседний случайный hue. Цвет иконки и её контекст не обязательно совпадают: системная коллекция Wishlist использует красное emoji ❤️ внутри розовой темы.

## Основные роли и источник

| Роль | Цвет | Токен/использование |
| --- | --- | --- |
| Основной фон | `#0b0d12` | `--bg` (общий `src/styles.css`) |
| Поверхность | `#12151c` и `#181c25` | `--surface` и `--surface-2` |
| Разделители | Белый 8/14% | `--line`, `--line-strong` |
| Основной акцент приложения | `#8cf27d` | `--accent` — интерактивные кнопки/фокус, отдельный от эмоциональных реакций |
| «Нравится» / зелёная позитивная реакция | `#92e9ae` | `--palette-like-rgb:146,233,174` — тема коллекций `emerald`, надписи/дымка Discovery |
| «Не нравится» / спокойный отказ | `#8ebaff` | `--palette-dislike-rgb:142,186,255` — тема коллекций `blue`, текст/дымка Discovery |
| «Хочу поиграть» / wishlist | `#ffa2ca` | `--palette-wishlist-rgb:255,162,202` — `rose`, текст/дымка; emoji ❤️ из общей иконки wishlist |
| Рейтинг IGDB | `#dfb6ff` | `--palette-igdb-rgb:223,182,255` — единый фиолетовый для бейджа в Discovery и IGDB-панели на странице игры; текст, рамка и тонированный фон |
| Основной текст | `#f7f7fa` | цвет `:root`, рядом нейтральные ослабленные подписи `--muted` |

**Единственный источник цифровых RGB-значений реакций и рейтинга IGDB:** `:root` в `src/styles.css`. Для CSS текста использовать `rgb(var(--palette-*-rgb))`, для прозрачных градиентов — `rgba(var(--palette-*-rgb), .7)`. Не копировать числовые значения в `DiscoverView.css` или в `collectionModel.ts`. Сами варианты коллекций `rose`, `blue`, `emerald` берут `accent` через `rgb(var(...))`; их `shade`/фон остается прежним. Рендер красного emoji ❤️ предоставляет `WishlistHeart` в `src/components/CollectionAppearance.tsx`.

## Исключения и миграция

Исторически у редактора коллекций остаются *десять* именованных тем: `violet`, `rose`, `blue`, `cyan`, `teal`, `emerald`, `lime`, `amber`, `orange`, `slate`. Это допустимая пользовательская настройка; **не удалять** и не переписывать сохранённые значения `colorScheme`. Со временем можно связать остальные оттенки с общими токенами по мере доработок, но не расширять палитру типичных реакций приложения. Красный цвет не применяется к «Не нравится» — избегаем ассоциации с ошибкой или удалением.

## Перед PR

Если интерфейс вводит цвет: определить роль → проверить этот справочник → использовать существующий CSS-токен → добавить тест значения и контраста по возможности → обновить эту страницу и `CHANGELOG.md` при реальном пересмотре палитры. Не считать документацию в `develop` принятой в production до одобрения владельца.

## Рекомендации и игровая карточка (PR #61)

В Discovery центральный текст свайпа проявляется быстрее полупрозрачной цветной дымки: используются независимые значения opacity, чтобы короткая протяжка не делала текст бледным. Дымка не усиливается. Стрелки, символ ❤️ и подпись — единый `inline-flex` ряд с явным отступом 6px и вертикальным центрированием; размеры обёртки подстраиваются для большой подписи результата. Использовать этот принцип для новых подписи/иконки, а не уповать на HTML-пробелы между emoji и текстом.

IGDB внутри стекла Discovery уже был фиолетовым. Теперь на странице игры `.detail-rating-panel--igdb` использует тот же `--palette-igdb-rgb` для текста числа, метки, фиолетовой рамки и полупрозрачной поверхности. Отдельный зелёный рейтинг Rate APP остаётся прежним.
