# Аудит тестов Rate APP — 27 октября 2026 года

**Цель:** не наращивать количество тестов ради каждого фикса. Сохранять проверки безопасности, данных, основных маршрутов и жестов; убирать неиспользуемые сервисы и хрупкие проверки декоративных CSS-токенов. Полный CI запускать перед production или по запросу владельца, а не при каждой итерации staging.

## Когда ждать в чате, а когда использовать Telegram

- **Быстрая точечная проверка / build ≤2 минут:** запустить и **дождаться итога в этом диалоге**, затем сообщить результат. Не создавать Telegram-оповещение специально для такого теста.
- **Длительный CI >5 минут:** запустить, дать прямую ссылку на живой GitHub Actions и закончить ожидание в чате; финальные красный/зелёный результаты поступают через `rateapp_cicd_bot`.
- **Между 2 и 5 минутами:** учитывать реальную оценку; не запускать полный CI только потому, что изменили стили. Для полного production-release CI применять Telegram даже при нормальном коротком прогоне: при retry он может превысить 5 минут.
- **Staging:** без полного набора тестов по умолчанию. Docker-сборка и API smoke — техническая проверка публикации, отдельно от QA.
- **Production:** полный build/backend/mobile E2E остаётся обязательным и блокирует merge при падении.

Этот аудит не доказывает, что оставленные UI-сценарии без дефектов: на текущей итерации полный E2E не запускался. После следующего полного релизного CI оценить отдельно таймауты Discovery, не скрывать настоящие падения простым увеличением `timeout`.


### Уточнение причины релизного блокера (27.10.2026)

Координаты тестового свайпа теперь берутся с `.discover-cover__gesture`, которая служит настоящим функциональным hitbox и существует независимо от того, успешно ли декодируется внешний `<img>` или используется `.discover-cover__fallback`. Прежняя обязательная проверка картинки перед жестом давала ложный отказ (PR #70) после возврата со страницы прохождения/закрытия подробностей. Доступность и `aria-label` свайп-поверхности проверяются прямо перед пан-жестом. Обязательный полный CI перед production остаётся без послаблений.
